# HMF Kinetics Fitter

**Authors:** Yefan Zhang, Jiquan Liu  
**Affiliation:** Northwest University  
**Version:** 1.0  
**Release Date:** January 2025

## Overview

The HMF Kinetics Fitting Tool is a professional Python-based software for analyzing and fitting reaction kinetics data of HMF (5-hydroxymethylfurfural) oxidation processes.

## Key Features

- Flexible Reaction Models (single-phase/two-phase)
- Advanced Optimization (PyTorch + Adam)
- Modern GUI Interface
- Real-time Progress Monitoring

## Quick Start

### Download Executable

1. Download from [Releases](https://github.com/zyf1121/HMF-Kinetics-Fitter/releases)
2. Double-click `HMF_Kinetics_Fitter.exe`
3. No Python installation required!

### Install from Source

```bash
git clone https://github.com/zyf1121/HMF-Kinetics-Fitter.git
cd HMF-Kinetics-Fitter
pip install -r requirements_exe.txt
python gui_fitter_en.py
```
